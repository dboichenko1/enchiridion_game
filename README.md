# Энхиридион. Практика

Интерактивная практика стоицизма для телефона (PWA): ты идёшь античным портиком, входишь в двери-главы и проживаешь каждый из 53 принципов «Энхиридиона» Эпиктета как сцену из сегодняшнего дня — выбираешь реакцию, видишь последствие, читаешь разбор с эпиграфом и голосом древнего комментатора Симпликия.

**▶ Играть: https://dboichenko1.github.io/enchiridion_game/**

- Полностью офлайн после первой загрузки, устанавливается на домашний экран (iOS/Android/десктоп).
- Без аккаунтов, без сети в рантайме, без аналитики. Прогресс живёт в браузере; переносится «кодом пути».
- Одна шкала — атараксия (равновесие): её несёт лампа Эпиктета в кадре. Очки за верную реакцию, не за удачный исход.

## О текстах

Оригинальные сценарии по мотивам «Энхиридиона» Эпиктета (общественное достояние). Эпиграфы — свободные переложения, выполненные заново; разборы и заметки «Симпликий поясняет» — пересказ идей своими словами. Ни одна фраза какого-либо современного перевода-источника здесь не используется.
